\# Первичная модель угроз

\## Лабораторная работа №1 — МСОСБ



Подгруппа: Тим, Вова, Никита

Предварительный номер X: 11



\### Архитектура

CLIENT: 10.10.11.10

GATEWAY: 10.10.11.1 / 10.20.11.1

SERVER: 10.20.11.10



\### Угроза 1. Перехват открытого HTTP/SMTP

Описание: наблюдатель может прочитать

данные незашифрованного соединения.

Защита: HTTPS/TLS, отказ от открытой

передачи чувствительных данных.

Доказательство: HTTP и SMTP в PCAP

читаются, TLS Application Data зашифрованы.



\### Угроза 2. Несанкционированный доступ к БД

Описание: CLIENT получает доступ

к внутреннему сервису PostgreSQL.

Защита: сегментация сети, nftables,

политика default deny.

Проверка: ЛР №2 и №4.



\### Угроза 3. Несанкционированный SSH-доступ

Описание: посторонний пользователь

пытается администрировать серверы.

Защита: отдельная ADMIN-сеть,

SSH-ключи, ограничения firewall.

Проверка: ЛР №2 и №4.



\### Угроза 4. ARP-spoofing

Описание: злоумышленник в локальном

сегменте подменяет соответствие IP и MAC.

Защита: изоляция L2-сегментов,

мониторинг ARP и контроль узлов.

Проверка: анализ ARP в Wireshark.



\### Угроза 5. Изменение передаваемых файлов

Описание: полученный файл отличается

от исходного или поступает от

недоверенного сервера.

Защита: проверка TLS-сертификата

и контроль SHA-256.

Проверка: ЛР №3.



\### Угроза 6. Перехват межплощадочного трафика

Описание: трафик между двумя площадками

доступен для пассивного наблюдения.

Защита: WireGuard VPN, маршрутизация

только разрешённых сетей.

Проверка: ЛР №3.
