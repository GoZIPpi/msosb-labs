|---|---|---|---|

\## 2. Внутренние подсети



client\_net:

Шлюз: 10.10.11.1

Клиент: 10.10.11.10



server\_net:

Сеть: 10.20.11.0/24

Шлюз: 10.20.11.1

Сервер: 10.20.11.10



\## 3. Маршрутизация



CLIENT:

Назначение: 10.20.11.0/24

Следующий узел: 10.10.11.1

Интерфейс: enp0s8



SERVER:

Назначение: 10.10.11.0/24

Следующий узел: 10.20.11.1

Интерфейс: enp0s8



GATEWAY:

10.10.11.0/24 — enp0s8

10.20.11.0/24 — enp0s9

IPv4 forwarding = 1



\## 4. Служебная сеть NAT



На всех трёх ВМ временно используется VirtualBox NAT.



Адрес внутри каждой отдельной NAT-среды:

10.0.2.15/24



Шлюз NAT:

10.0.2.2



Назначение:

\- Установка и обновление пакетов.

\- Администрирование через SSH.

\- Временный доступ в интернет.



NAT-сети каждой ВМ независимы.

Одинаковые IP-адреса не вызывают конфликта.



\## 5. Сервисы SERVER



HTTP: TCP 80

HTTPS: TCP 443

DNS: UDP 53

SMTP: TCP 2525

SSH: TCP 22



\## 6. Результаты проверок



CLIENT -> GATEWAY: успешно

SERVER -> GATEWAY: успешно

CLIENT -> SERVER: успешно

SERVER -> CLIENT: успешно



Потери ICMP: 0%



Маршрутизация сохраняется после перезагрузки.



TTL ICMP на client\_net: 64

TTL ICMP на server\_net: 63



Разница TTL подтверждает прохождение

пакета через маршрутизатор GATEWAY.



\## 7. Примечания



Адресация X = 11 является предварительной.

При изменении номера подгруппы

IP-адреса необходимо скорректировать.



Служебные NAT-интерфейсы пока включены.

Изолированные сети client\_net и server\_net

используются для лабораторного обмена.
